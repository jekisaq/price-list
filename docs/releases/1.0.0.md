# Price List 1.0.0

Подготовлен 27.10.2026. Платформа релиза: Windows x64, установщик NSIS.

## Возможности

- CSV/XLSX, предпросмотр, кодировки и разделители, выбор листа и строки заголовков.
- Сопоставление русских колонок, три обязательных поля результата.
- Проверка цен и дублей, исправление артикулов, наценка и округление.
- Отчёт по исходным строкам и экспорт отчёта CSV.
- Готовый прайс CSV/XLSX, строковые артикулы и числовые цены XLSX.
- Профили между запусками, worker, страницы предпросмотра, прогресс и отмена.
- Установка для текущего пользователя, ярлыки и удаление с сохранением данных.

## Комплект

`npm run release:prepare` собирает существующий установщик, инструкцию и небольшие
примеры в `release/Price-List-1.0.0-windows-x64/`:

| Файл | Назначение |
| --- | --- |
| `Price-List-1.0.0-x64-Setup.exe` | Установщик |
| `user-guide.md` | Русская инструкция пользователю |
| `1.0.0.md` | Описание релиза |
| `README.txt` | Краткий порядок запуска |
| `samples/` | Вымышленные исходные CSV/XLSX и готовые прайсы с наценкой 20% |
| `SHA256SUMS.txt` | SHA-256 файлов комплекта |

Готовый архив комплекта: `release/Price-List-1.0.0-windows-x64.zip`.
Он подготовлен локально для передачи или последующей публикации; удалённый
релиз, тег Git и загрузка на сторонние сервисы не выполняются автоматически.

Проверенный установщик: 129 029 945 байт. SHA-256:
`542BC153F54DC9DCCFF54893E51DDEA605194E0B9065DC3D64E5DF8A8B06CD7D`.
В PowerShell сравните результат `Get-FileHash .\Price-List-1.0.0-x64-Setup.exe -Algorithm SHA256`.

Для пересборки из исходников:

```powershell
npm.cmd ci
npm.cmd run demo:capture
npm.cmd test
npm.cmd run test:smoke
npm.cmd run test:performance
npm.cmd run test:packaged
npm.cmd run dist
npm.cmd run release:prepare
Compress-Archive -Path release/Price-List-1.0.0-windows-x64 -DestinationPath release/Price-List-1.0.0-windows-x64.zip -Force
```

Пересборка может изменить байты установщика и SHA-256. Приведённый хеш относится
к сохранённому артефакту, проверенному в Sandbox. Для нового EXE повторите
`scripts/start-windows-sandbox.ps1`, обновите отчёт проверки и хеш в описании.
`release:prepare` вычисляет хеши фактических файлов, но не заменяет проверку EXE.

## Проверено и ограничено

Пройдены модульные тесты, Electron workflow/профили, тест больших файлов,
упакованный EXE и чистая Windows Sandbox (см. `docs/windows-validation.md`
в репозитории).
Сценарии создания демонстрации также проверяют реальный экспорт и отмену.

Установщик не подписан. Чистый прогон использует тихую установку и администратора
Sandbox; SmartScreen, мастер установки и обычный пользователь без прав
администратора отдельно не проверены. Windows 10 отдельно не проверялась.
Нет автообновления, облачной синхронизации и интеграции с учётными системами.
Лимиты данных и особенности формул XLSX описаны в инструкции. Отдельная среда
разработки конечному пользователю не требуется.
