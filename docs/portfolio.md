# Price List — проект для портфолио

## Задача

Магазин получает прайс-листы от разных поставщиков. В одном файле артикул
называется «Код товара», в другом — «Артикул»; цены и кодировки различаются,
встречаются дубли и пустые поля. Ручная подготовка одного формата требует
повторять сопоставление, проверку и расчёт при каждом поступлении файла.

Price List превращает этот процесс в последовательность: импорт → сопоставление
→ проверка → экспорт. Файлы обрабатываются локально; сохранённый профиль
поставщика можно использовать при следующем импорте.

## Что реализовано

Electron-приложение с React/MUI и строгим TypeScript: main отвечает за окно,
диалоги, проверку IPC и настройки; preload предоставляет ограниченный API;
renderer отображает шаги; отдельный worker читает и обрабатывает данные.
Денежные расчёты используют целые копейки и BigInt. Ведущие нули артикула
сохраняются. Ошибки связаны с исходными строками, дубли требуют выбранного правила,
а пропуск исключённых записей подтверждается перед экспортом.

Обработка больших файлов сопровождается прогрессом и отменой. UI получает
страницы и сводки, таблицы виртуализированы. CSV/XLSX экспортируется через
временный файл с очисткой при неудаче. Профили сохраняются атомарно с проверкой
версии и восстановлением после повреждения. Подготовлен Windows NSIS-установщик.

## Доказательства

- [Короткая демонстрация и снимки](demo.md) показывают реальные состояния UI.
- [Исходные и готовые прайсы](../samples/README.md) позволяют воспроизвести результат.
- [Замер на Ryzen 5 7500F / 32 ГиБ](performance.md): CSV 100 000 товаров — 576 мс,
  XLSX 25 000 — 382 мс на полный путь от импорта до экспорта в одном прогоне.
- [Чистая Windows Sandbox](windows-validation.md): установка, запуск без Node.js
  и Excel, CSV/XLSX, перезапуск с профилем и удаление проверены автоматически.
- `npm test`, Electron smoke, performance и packaged smoke проверяют расчёты,
  IPC, жизненный цикл данных, экспорт, профили и большие файлы.

Это демонстрационный проект, а не внедрение у реального магазина. Измеренной
экономии рабочего времени и коммерческих результатов пока нет. Данные вымышлены;
ограничения, условия замеров и непроверенные ручные сценарии указаны в документации.

## Для каких заказов применим этот опыт

| Задача заказчика | Что можно показать в проекте |
| --- | --- |
| Приведение таблиц поставщиков к единому формату | Настраиваемые колонки, русские заголовки, CSV/XLSX |
| Автоматизация повторяющейся подготовки прайсов | Профили, наценка и округление, повторный импорт |
| Проверка качества данных перед загрузкой в учётную систему | Обязательные поля, дубли, отчёт с исходными строками |
| Локальное приложение для бизнеса | Установщик, работа без сети и отдельной среды разработки |
| Отзывчивый интерфейс при больших файлах | Worker, страницы IPC, виртуализация, прогресс и отмена |

Для интеграции с конкретной ERP, складом или маркетплейсом потребуются отдельные
требования и реализация адаптера: таких подключений в текущем проекте нет.

## Короткое описание для отклика

> Разработал локальное приложение подготовки прайс-листов на Electron, React и
> TypeScript. Реализовал импорт CSV/XLSX, сопоставление колонок, проверку ошибок
> и дублей, точный расчёт наценки и экспорт. Разделил main/preload/renderer,
> организовал типизированный IPC и worker для тяжёлых операций, добавил прогресс,
> отмену, профили поставщиков и Windows-установщик. В репозитории есть примеры,
> демонстрация, автоматические проверки и замеры больших файлов с описанием среды.
