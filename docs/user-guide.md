# Price List — инструкция пользователя

Приложение преобразует таблицу поставщика в прайс с колонками «Артикул»,
«Наименование», «Цена». Все три поля обязательны. Обработка выполняется локально.

## Установка и удаление

Нужна Windows 10/11 x64. Чистый прогон выполнен на Windows 11; Windows 10 отдельно
не проверялась. Запустите `Price-List-1.0.0-x64-Setup.exe`, выберите каталог и
завершите установку. Откройте Price List через ярлык рабочего стола или меню «Пуск».
Node.js, npm, Excel и подключение к сети для работы не требуются.

Установщик пока не подписан сертификатом издателя. Поведение SmartScreen не
проверено; при предупреждении убедитесь в происхождении файла и сверьте его
SHA-256 с комплектом релиза. Не устанавливайте файл неизвестного происхождения.

Для удаления закройте приложение и найдите Price List в «Установленных
приложениях» Windows. Удаление сохраняет экспортированные файлы и профили.
Настройки находятся в `profiles.json` в пользовательском каталоге приложения
(при стандартной установке Windows — `%APPDATA%\price-list`).

## Первый прайс

1. Нажмите «Выбрать CSV / XLSX…» и откройте `samples/csv/supplier-basic.csv`.
   Укажите UTF-8, запятую и строку заголовков 1. Для XLSX выберите нужный лист.
2. Нажмите «Показать предпросмотр»: в примере 10 товаров. Перейдите к сопоставлению.
3. Проверьте пары «Код товара» → «Артикул», «Название» → «Наименование»,
   «Стоимость» → «Цена». Остаток не нужен для итогового прайса.
4. Задайте наценку 20%, округление «До ближайшего», шаг 0.01. Нажмите
   «Проверить и рассчитать». Для товара `001` исходная цена 120, итоговая — 144.
5. Перейдите к экспорту, выберите CSV или XLSX и сохраните файл через диалог.
   Результат должен содержать 10 товаров. Образцы лежат в `samples/output/`.

Вывод CSV использует UTF-8 с BOM и `;`. Если открываете готовый прайс снова,
выберите этот разделитель и наценку **0%**, чтобы не увеличить цены ещё раз.
XLSX можно открыть непосредственно в табличном редакторе; артикулы записаны текстом.

## Ошибки и дубли

Откройте `supplier-invalid.csv`, чтобы увидеть отсутствующие поля, неверные цены
и повторы артикула. В отчёте указаны исходная строка, колонка, значение и причина.
Фильтр позволяет отдельно увидеть ошибки, дубли, предупреждения и исключения.
Отчёт CSV можно сохранить даже тогда, когда экспорт прайса заблокирован.

Для дублей выберите «Оставить первую строку», «Оставить последнюю строку» или
ручной режим. В ручном режиме можно исправить артикулы повторов в отчёте и
пересчитать. Другие ошибки исправьте в исходном файле, затем импортируйте его
заново. Для исключённых дублей перед экспортом требуется явное подтверждение
пропуска. Отсутствующие обязательные значения автоматически не заполняются.

## Повторный импорт

Введите название поставщика в блоке профилей и нажмите «Сохранить как новый».
Профиль запоминает параметры чтения, сопоставление, наценку, округление и правило
дублей. При следующем запуске выберите профиль и откройте новый файл поставщика.
При изменении заголовков проверьте предупреждение и заново сопоставьте колонки.
Для изменения профиля используйте «Обновить профиль…»; доступны переименование
и удаление. При предупреждении о настройках сохранение может быть отключено —
путь проблемного файла и причина отображаются в приложении.

## Большие файлы и ошибки сохранения

Во время операции отображаются этап, количество строк и процент, если объём
известен. Для остановки нажмите «Отменить операцию», затем «Остановить».
После подтверждения незавершённый результат отбрасывается. Если worker пришлось
остановить принудительно, откройте исходный файл заново.

Если сохранение не удалось, закройте файл в другом приложении и выберите папку,
в которую у вас есть права записи. Прежний файл сохраняется при отмене или ошибке
подготовки; повторите экспорт в другое назначение.

Лимиты: 100 МиБ на файл, 500 000 исходных записей с заголовком, 256 колонок,
4 млн ячеек. XLSX с паролем не поддерживается. Формулы не пересчитываются:
используется сохранённый результат; при его отсутствии пересчитайте книгу в
табличном редакторе и сохраните её перед импортом. Произвольные форматы Excel,
макросы, конвертация валют и налоговый учёт не реализованы.
