# Примеры прайс-листов

Все поставщики и товары вымышлены. Цены в рублях, без наценки магазина.

| Папка / файл | Содержимое | Как импортировать |
| --- | --- | --- |
| `csv/supplier-basic.csv` | 10 товаров, кириллица, артикул `001` | UTF-8, запятая, заголовок 1 |
| `csv/supplier-invalid.csv` | Пустые обязательные поля, цены с ошибками, дубль | UTF-8, запятая, заголовок 1 |
| `csv/supplier-duplicates.csv` | 3 строки, повтор `001` | UTF-8, запятая, заголовок 1 |
| `xlsx/supplier-basic.xlsx` | 3 товара, текстовый артикул `000001`, числовые цены | Лист «Товары», заголовок 1 |
| `xlsx/supplier-invalid.xlsx` | 7 строк: дубль, пустые поля, неверные цены | Лист «Товары», заголовок 1 |
| `xlsx/supplier-duplicates.xlsx` | Те же данные, что в CSV с дублями | Лист «Товары», заголовок 1 |

В XLSX и новых CSV сопоставьте «Артикул», «Наименование», «Цена» с одноимёнными
колонками. Для остальных CSV см. `csv/README.md`.
При наценке 20% первый товар XLSX стоит 144.00, артикул остаётся `000001`.
В примере дублей ручной режим блокирует экспорт; «первая» оставляет цену 12.00,
«последняя» — 24.00. Для экспорта необходимо подтвердить исключение другой строки.
В XLSX с ошибками все 7 строк имеют ошибки при ручном разрешении дублей.

## Большие файлы

Запустите `npm run samples` (PowerShell: `npm.cmd run samples`). Команда воссоздаёт
небольшие XLSX и записывает большие файлы в игнорируемую Git папку `generated/`:

- `prices-100000.csv` — 100 000 товаров;
- `prices-400000.csv` — 400 000 товаров, удобно проверять отмену;
- `prices-25000.xlsx` — 25 000 товаров, лист «Товары».

CSV: UTF-8, запятая, заголовок 1. Артикулы от `00000001`, цена 10.25;
при наценке 20% и округлении до копеек результат — 12.30.
Команда перезаписывает только эти известные примеры. Для автоматических замеров
используйте `npm run test:performance`: он создаёт отдельные файлы в `out/tests/`.
