# Готовый прайс

`price-markup-20.csv` и `price-markup-20.xlsx` экспортированы самим приложением
из `../csv/supplier-basic.csv` во время `npm run demo:capture`.
Все товары вымышлены. Исходный столбец «Остаток» пропущен.

Параметры: наценка 20%, до ближайшего, шаг 0.01, ручной режим дублей.
Результат — 10 товаров, колонки «Артикул», «Наименование», «Цена».
Первая строка: `001`, `Блокнот А5`, `144.00`; последняя цена — `81.00`.

CSV: UTF-8 с BOM, `;`, CRLF, цена с точкой и двумя знаками. XLSX: артикул
как текст, цена как число. Для повторного импорта готового файла используйте
наценку 0%, чтобы цены не увеличились повторно.
